Features

Everything you need.
Nothing you don't.

Built on native macOS APIs so it feels exactly like it belongs — because it does.

🔁

Find & Replace

Native macOS find bar with incremental search and full replace support. Instantly highlight every match as you type.

⌘F  ·  ⌘⌥F
🔠

Font Customization

Open the native macOS Font Panel to pick any font installed on your system — size, weight, style. Your choice is remembered.

⌘,
🔍

Zoom

Scale the editor text independently of the font size. Zoom in for focused writing or zoom out for a wider view. Shown in the status bar.

⌘=  ·  ⌘-  ·  ⌘0
📝

Word Wrap

Toggle word wrap with a single click in the status bar. Long lines scroll horizontally when wrap is off.

⌘⌥Z
📍

Go to Line

Jump directly to any line number in your document. Essential for log files, code snippets, and long notes.

⌘L
🕐

Insert Date & Time

Stamp the current date and time at your cursor position in one keystroke. Supports undo like any other edit.

⌘⇧T
🎨

Screen Color Picker

Pick any color from anywhere on your screen and insert its hex value (#RRGGBB) directly at the cursor. Perfect for design notes.

⌘⇧H
🖨

Print & Page Setup

Full native print support with copies, page range, orientation, scaling and PDF export — exactly what macOS users expect.

⌘P  ·  ⌘⇧P
📂

Drag & Drop Open

Drop a text file onto the app icon to open it. File association lets the system route .txt files to FastNote automatically.
